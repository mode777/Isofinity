Dynamic-mesh pipeline debug

Escalating stages of the mesh path. Each row isolates one layer; the first broken row localizes the fault:

  1. unskinned cube — attributes + projection + palette-uniform mechanics with known data
  2. bind pose — real CesiumMan geometry + indices, identity palette, no texture
  3. frozen pose — real palette data (t = 0), no animation
  4. animated — per-frame palette upload
  5. textured — the full editor path (texture + SH ambient + ACES)
