Isofinity — Bake Tool

Bakes a primitive or glTF model into per-asset sprite passes: albedo (sRGB PNG), a merged g-buffer (float EXR: rgb = world-space normal, a = linear ray depth), and — path traced over the same camera — an optional HDRI-lit render pass (ACES) and AO pass. World position is reconstructible from pixel + depth via the fixed camera; a debug PNG dumps the reconstructed cube-space position for validation.
